# Como usar Codex para seguir mejorando este sitio

## Flujo recomendado

1. Abre esta carpeta como proyecto en Codex.
2. Pide cambios concretos, por ejemplo: "agrega una pagina para otra IA", "mejora el hero", "hazlo mas liviano" o "separa el blog en nuevas paginas".
3. Revisa el resultado localmente abriendo `index.html` en el navegador.
4. Cuando estes conforme, sube los cambios al repositorio de GitHub.

## Prompts utiles para Codex

- "Agrega una nueva IA al catalogo con pagina individual, manteniendo el mismo estilo visual."
- "Optimiza el CSS para que cargue mas rapido sin perder el estilo futurista."
- "Crea una pagina de blog para esta noticia y enlazala desde el inicio."
- "Revisa el sitio como si fueras profesor y dime que mejorarias para una exposicion universitaria."

## Recomendacion

Para SEO real, convierte las noticias editables en entradas HTML propias y agrega referencias verificadas. Para un prototipo universitario, la estructura actual ya es solida y presentable.
